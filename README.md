# AaTu_EXUp

在锻造台为武器、护甲注灵并强化属性。

## 成品

Minecraft 1.21.1。

- NeoForge [aatu_exup-1.0.9-neo.jar](artifacts/neoforge/aatu_exup-1.0.9-neo.jar)
- Fabric [aatu_exup-1.0.6-fabric.jar](artifacts/fabric/aatu_exup-1.0.6-fabric.jar)

## 构建

使用 JDK 21，进入 `fabric/` 或 `neoforge/` 后执行 `.\gradlew.bat assemble -x test`。
